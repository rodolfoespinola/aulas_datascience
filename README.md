# 📊 Data Science with Python — SCTEC 

> Practical exercises and scripts developed during the **Introduction to Data Science (SCTEC)** course.
> The goal is to develop skills in **Python for Data Analysis**, analysis, visualization, and dataset preparation, with a focus on professional roles in **Data Science, Cybersecurity, Cloud, and Analytics**

Este repositório reúne exercícios e scripts desenvolvidos durante o curso **Introdução à Ciência de Dados (SCTEC)**.  
O objetivo é desenvolver competências em **Python para Análise de Dados**, análise, visualização e preparação de datasets, com foco em atuação profissional em **Data Science, Cibersegurança, Cloud e Analytics**.

---

### 🧠 Tecnologias e tópicos

- 🐍 Python  
- 📐 NumPy — computação numérica  
- 🗃 Pandas — análise e manipulação de dados  
- 📊 Matplotlib — visualização  
- 🎨 Seaborn — visualização estatística  
- 📈 Estatística aplicada  
- 🧹 Limpeza e preparação de dados
